# WijkRichting

Publieke, statische presentatie van vooraf berekende wijkanalyses.

De analysemotor, feature-engineering, validatie en matchinglogica staan **niet**
in deze repository. Deze repository bevat alleen:

- HTML/CSS/JavaScript voor presentatie;
- vooraf berekende publieke JSON-resultaten;
- eventueel openbare PDF-rapporten.

De data worden gegenereerd in een private analysemotor en vervolgens als
statische output gepubliceerd.

## GitHub Pages

Publiceer vanaf de root van de `main` branch via:

**Settings → Pages → Deploy from a branch → main → /(root)**

De site gebruikt geen backend en doet geen analytisch rekenwerk in de browser.
