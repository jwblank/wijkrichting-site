# WijkRichting 2.0 — publieke site

Deze openbare repository bevat uitsluitend:

- de statische presentatielaag van [WijkRichting](https://jwblank.github.io/wijkrichting-site/);
- vooraf berekende, publieke JSON-uitvoer onder `data/`;
- de minimale GitHub Pages-publicatieconfiguratie.

De databuild, bronverwerking, analyses, validatiecode en modelmethodiek staan in
een afzonderlijke private repository. De browser voert geen analyse of matching
uit. Een automatische grenscontrole blokkeert publicatie als broncode of
brondata buiten de toegestane sitebestanden in deze repository terechtkomt.
